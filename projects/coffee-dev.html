Coffee Dev

Engineering activity, turned into an idle simulation worth caring about.

Coffee Dev takes repository activity and turns it into an idle simulation for software engineers. It started from a simple frustration around review bottlenecks and grew into a broader idea about engagement, progress, and giving engineers a space that feels more rewarding than another metrics screen.

  • Turns commits, pull requests, and related activity into visible progression.
  • Rewards engagement with a personal cafe, currency, and idle simulation systems.
  • Gives users direct control over their space through purpose-built management tools.
Watch this space Next project

Why it matters

It began with code review bottlenecks, but the larger idea is about engineering engagement. Instead of laying a shiny UI over existing metrics, the product tries to make contribution feel more tangible, more motivating, and a bit more human.

What it proves

I can take a rough idea, stay hands-on through product and engineering decisions, and use AI as a force multiplier without treating it as an autopilot. The work has been heavily planned, refined, and directed rather than blindly accepted.

Current shape

The project is still a work in progress, but the core loop is already there. It can connect to repositories, generate a cafe, support user decisions, and run progression, currency, and idle simulation systems in the browser.

Hard part

The toughest part has been the growing complexity around object placement, character management, and movement fidelity. As the idea expanded, I built GUIs to reduce user friction, and I am currently refining character motion across prompt iteration, system design, and pixel-art constraints.
